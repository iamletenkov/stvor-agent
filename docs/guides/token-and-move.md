# Токен и переезд робота

Токен меток выпускает портал Stvor: карточка робота → блок «Метки» → «Выпустить токен меток» или
«Перевыпустить» (показывается один раз). Секрет регистрации Teleport («Новый секрет») — другое: им
занимается расширение `teleport` (`cream run teleport join`), токен меток он не меняет.
Токен — только через stdin, никогда в аргументах, переменных окружения сессии или истории оболочки.

## 1. Включить агент (токена нет или файл испорчен)

```sh
read -rs T && printf '%s' "$T" | sudo stvor-agent enable URL=https://<домен>/robot-api/v1/labels; unset T
```

`enable` пишет `/etc/stvor-agent/token` (0600 root), включает и перезапускает службу и делает один
синхронный `sync`. Проверка — [«Диагностика»](diagnostics.md) §1: `token=ok`, `enabled=true`,
`last_poll.outcome` = `ok`/`not_modified`; метка `stvor_agent` получает версию за ≤ 5 мин.

## 2. Перевыпуск токена

Когда: токен утёк, робот переустановлен, команда включения потеряна, в журнале `outcome=unauthorized`.

1. Портал: карточка робота → «Метки» → «Перевыпустить». Прежний токен перестаёт приниматься сразу:
   служба получает 401 и спит 600 с между попытками, метки не трогает.
2. Робот: команда §1 с новым токеном и тем же адресом (`state.json` сохраняется, служба просыпается сразу).
3. Проверка: `sudo stvor-agent status --json` → `last_poll.outcome` не `unauthorized`; на карточке нет
   «Метки расходятся».

## 3. Переезд робота

| Случай | Что делать |
|---|---|
| Другое пространство или окружение в том же портале | только портал: перенос робота на карточке; агент применит `env`/`space` и перезапустит Teleport сам (обычно до 2 минут). На роботе — ничего |
| Портал сменил домен | на портале перевыпустить токен (§2), на роботе — §1 с новым `URL=`: другой адрес сбрасывает `state.json`, первый тик берёт метки с нуля. Регистрацию в Teleport меняет расширение `teleport` (новый прокси — `cream run teleport join` с новым секретом), агент её не касается |
| Машина заменена или ОС переустановлена | установка заново по способу из карточки робота (скрипт портала или `cream install` + `stvor-agent enable`, см. [установку на робота](install-on-robot.md)); «Новый секрет» для `join` и перевыпуск токена меток (§2): прежний токен остался на старой машине |
| Робот выводится из работы | `sudo stvor-agent disable` (служба выключена, токен и `state.json` удалены; `env`/`space` в Teleport остаются, `stvor_agent` пустеет за ≤ 5 мин), затем `sudo cream run teleport leave` — снимает регистрацию и управляемые метки; на портале — списание робота (удаляет токен) |

Проверка после переезда: [«Диагностика»](diagnostics.md) §1 и §4 — `in_effect=true`, `env`/`space`
узла в Teleport равны порталу, `stvor_agent=<версия>`.
