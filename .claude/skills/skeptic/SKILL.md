# Skeptic: $ARGUMENTS

- Путь в `docs/specs/` или `docs/plans/` — прочитай файл целиком.
- `diff` или пусто — `git diff main...HEAD` (на main — `git diff HEAD`).
- Иначе — описание реализации; непонятно, что ревьюить, — один уточняющий вопрос и стоп.

Верни риски по своему формату. Найденное вызывающий вносит в спеку/план до реализации.
