# Go

- **Структура:** `cmd/<бинарь>/main.go` — только разбор аргументов и вызов `run(args, stdout, stderr) int`; логика — в `internal/<пакет>/`. `pkg/` не заводим, пока нет внешнего потребителя.
- **Сборка:** один статический бинарь — `CGO_ENABLED=0`, `-trimpath`, версия через `-ldflags "-X …/internal/version.Version=…"`; цели linux/amd64 и linux/arm64. Всё через `make` в контейнере `golang:1.25.11`, Go на хосте нет.
- **Зависимости:** stdlib по умолчанию. Новая зависимость — решение спеки/ADR, а не удобство одной функции; `go.sum` коммитится.
- **Без глобального состояния:** никаких изменяемых package-level переменных и `init()` с побочными эффектами (исключение — `version.Version` под ldflags). Конфигурация, логгер, файловая система, часы, исполнитель команд — передаются явно (параметр или поле структуры), чтобы тест подменял их.
- **Ошибки:** возвращаются, а не печатаются в глубине; оборачиваются с контекстом `fmt.Errorf("установка %s: %w", name, err)`; сравнение — `errors.Is/As`. `panic` — только на нарушение инварианта программы. Код выхода и текст для человека решает `run`.
- **Тесты:** table-driven (`tests := []struct{…}` + `t.Run(tc.name, …)`), `t.TempDir()` вместо реальных путей, `t.Parallel()` где нет общего состояния. Тест пишется до кода (TDD). Внешние команды и сеть — через интерфейс с фейком в тесте.
- **Ввод извне** (манифесты, переменные, вывод команд) — валидировать на границе; в `exec.Command` аргументы списком, никогда `sh -c` со склейкой строк.
- **Формат и линт:** `gofmt` (хук после правки), `make lint` (gofmt -l, go vet, golangci-lint). Подавление линтера — `//nolint:<линтер> // причина`.
