# Документация: где что лежит

| Что | Где | Формат |
|---|---|---|
| Индекс документации | `docs/README.md` | таблица «документ → зачем читать»; **новый документ без строки здесь — не готов** |
| Состояние работ (handoff между сессиями) | `docs/STATUS.md` | ≤ 30 строк: фаза / сделано / дальше / сломано; первые 40 строк подмешивает SessionStart-хук |
| Архитектурные решения | `docs/adr/NNNN-slug.md` | MADR по `docs/adr/0000-template.md`, строка в `docs/adr/README.md` |
| Спеки (что и почему) | `docs/specs/YYYY-MM-DD-slug.md` | раздел «Отвергнутые варианты» обязателен |
| Планы (как) | `docs/plans/YYYY-MM-DD-slug.md` | тот же slug, `## Progress Tracker` в шапке |
| Исследования | `docs/research/YYYY-MM-DD-slug.md` | отчёты, сравнения, внешние практики |
| Изменения версии | `CHANGELOG.md` | ведёт release-please, руками не правим |

Правила:
1. ADR — когда решение трудно откатить (формат файлов, CLI, пути на машине, имя пакета, лицензия) или оно неочевидно. Пересмотр — новый ADR с `Supersedes NNNN`.
2. Спека до плана, план до кода. План без спеки — только для bounded-задачи.
3. Принятая спека/ADR без «TBD»: решение или открытый вопрос с владельцем.
4. `AGENTS.md`/`CLAUDE.md` — регламент, а не журнал: история — в git и планах, процедуры — в `make` и `docs/`.
5. Ссылки относительные. Документация — по-русски; имена файлов — латиницей.
