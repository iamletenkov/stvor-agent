# Shell

- Шапка: `#!/usr/bin/env bash` (или `#!/bin/sh`, если скрипт исполняется там, где bash нет — OpenWrt), затем `set -euo pipefail` (в POSIX sh — `set -eu`). Исключение — скрипты-прогонщики проверок, которые обязаны дойти до конца: там `set -uo pipefail` и явный `rc`.
- Кавычки вокруг каждой подстановки; массивы для списков аргументов; `[[ ]]` в bash. Внешний ввод (переменные настроек, вывод команд) в `eval`/`sh -c` не склеивать.
- Идемпотентность: повторный запуск на той же машине даёт тот же результат и не падает (проверка «уже сделано» перед действием).
- Скачанное проверяется по sha256 до использования; временные файлы — `mktemp` + `trap … EXIT`.
- Секреты не печатаются и не передаются аргументами командной строки (видны в `ps`).
- `shellcheck` чистый: новый скрипт — на уровне `warning`, существующий — не хуже, чем был (`make lint` держит планку). Подавление — `# shellcheck disable=SCxxxx  # причина`.
- Тест на поведение — в тестовых скриптах репозитория на подменённом корне (`ROOT=$(mktemp -d)`), без root и без сети; пишется до правки.
